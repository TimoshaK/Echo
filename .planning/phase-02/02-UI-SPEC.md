## Spacing Scale

tkinter uses pixel-based padding via `padx`/`pady` parameters. Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing, widget padding |
| lg | 24px | Section padding, frame padding |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: none

**Source:** Inherited from Phase 1 UI-SPEC — 8-point scale standard.

---

## Typography

tkinter uses `tkinter.font.Font` for text styling. Use system default font family.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 12px | regular (400) | 1.4 |
| Label | 12px | regular (400) | 1.2 |
| Heading | 16px | bold (700) | 1.2 |
| Display | 20px | bold (700) | 1.1 |

**Note:** tkinter doesn't support fractional line-height; use `spacing1`/`spacing2`/`spacing3` options on Text widgets if needed. For Label/Button widgets, line-height is implicit.

**Source:** Inherited from Phase 1 UI-SPEC.

## Color

tkinter.ttk uses native OS theme by default. For custom styling, use ttk.Style().

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | System window color (#F0F0F0 Windows, #ECECEC macOS) | Background, main window |
| Secondary (30%) | System button face color (#E1E1E1) | Cards, frames, disabled states |
| Accent (10%) | System highlight color (#0078D4 Windows, #007AFF macOS) | Focus rings on buttons and entry fields only |
| Destructive | System error color (#D32F2F) | Error states in status label, destructive actions only |

**Accent reserved for:** Focus rings on interactive elements only (Select File button, Transcribe button, Entry fields). NOT used for status text or progress indicators.

**Destructive reserved for:** Error state text in status label and error messagebox title/icon. NOT used for normal processing feedback.

**Source:** Inherited from Phase 1 UI-SPEC. Destructive role now active for Phase 2 error states (ERRR-01).

## Window Layout

### Main Window

| Property | Value |
|----------|-------|
| Title | "Whisper Transcriber" |
| Default size | 600×450 pixels |
| Minimum size | 500×350 pixels |
| Resizable | Yes (both directions) |
| Position | Centered on screen |

**Size rationale:** Phase 1 was 500×200 (button + entry + status). Phase 2 adds a result text area requiring ~250px height. Total: 450px height. Width increased to 600px for comfortable text display.

### Widget Layout (Grid)

```
Row 0: [Select File Button] [File Path Display (Entry)]
Row 1: [Transcribe Button]  [Status Label]
Row 2: [Result Text Area — spans both columns]
```

| Widget | Type | Grid Position | Sticky | Pad |
|--------|------|---------------|--------|-----|
| Select File button | ttk.Button | (0, 0) | W | padx=8, pady=8 |
| File path display | ttk.Entry | (0, 1) | EW | padx=8, pady=8 |
| Transcribe button | ttk.Button | (1, 0) | W | padx=8, pady=8 |
| Status label | ttk.Label | (1, 1) | W | padx=8, pady=8 |
| Result text area | tk.Text | (2, 0) | NSEW | padx=8, pady=(8, 8) |

**Column weights:** Column 1 (file path, status) expands to fill window width.
**Row weights:** Row 2 (result text area) expands to fill remaining vertical space.

### File Path Display Behavior

- **Widget:** ttk.Entry (read-only state)
- **State:** `readonly` after file selected, `normal` when no file
- **Placeholder:** "Файл не выбран" (gray text)
- **Content:** Full absolute path of selected file
- **Source:** Inherited from Phase 1 UI-SPEC

### Result Text Area Behavior

- **Widget:** tk.Text with vertical scrollbar
- **State:** `disabled` initially and during transcription, `normal` only after successful result
- **Scrollbar:** ttk.Scrollbar attached to Text widget, placed in column 2 (or adjacent)
- **Wrap:** `word` wrap mode for readable text
- **Font:** System default, 12px body weight
- **Padding:** Internal padx=4, pady=4 for comfortable reading
- **Behavior:** Text is selectable and copyable after transcription completes
- **Initial content:** Empty (no placeholder — empty state is implied by empty widget)

### Scrollbar Layout

| Widget | Type | Grid Position | Sticky | Pad |
|--------|------|---------------|--------|-----|
| Result scrollbar | ttk.Scrollbar | (2, 1) | NS | pady=(8, 8) |

**Note:** Scrollbar is attached to Text widget via `command` linkage. Only appears when content overflows.

## Interaction States

### Transcribe Button States

| State | Appearance | Behavior |
|-------|------------|----------|
| Disabled | Grayed out (ttk default) | No file selected — cannot click |
| Normal | Standard ttk button | Click starts transcription |
| Hover | OS default hover style | Highlight on mouse over |
| Active (pressed) | OS default pressed style | Click triggers transcription |
| Processing | Disabled (grayed out) | Transcription in progress — cannot click again |

### Button State Transitions

```
No file selected → Disabled
File selected → Normal (enabled)
Click → Processing (disabled)
Transcription complete → Normal (enabled)
Transcription error → Normal (enabled)
New file selected → Normal (enabled, resets result area)
```

### Status Label States

| State | Text | Color |
|-------|------|-------|
| No file selected | "Нажмите «Выбрать файл», чтобы выбрать аудиофайл для транскрипции" | Default label color |
| File selected | "Выбран: {filename}" | Default label color |
| Transcribing | "Выполняется транскрипция..." | Default label color |
| Complete | "Готово! Язык: {detected_language}" | Default label color |
| Error | "Ошибка: {error_description}" | Destructive color (#D32F2F) |

### Result Text Area States

| State | Content | Editable |
|-------|---------|----------|
| Empty (initial) | "" (empty) | No (disabled) |
| Processing | "" (empty, cleared from previous run) | No (disabled) |
| Complete | Full transcription text | No (disabled, but selectable/copyable) |
| Error | "" (empty, unchanged) | No (disabled) |

**Note:** Text area stays `disabled` at all times. Users select and copy text but cannot edit it. This prevents accidental modification of transcription results.

## Processing Flow

### Transcription Lifecycle

1. **Idle:** Transcribe button disabled, status shows empty state, result area empty
2. **File selected:** Transcribe button enabled, status shows "Выбран: {filename}"
3. **Transcription started:** Transcribe button disabled, status shows "Выполняется транскрипция...", result area cleared
4. **Transcription complete:** Transcribe button re-enabled, status shows "Готово! Язык: {language}", result area shows text
5. **Transcription error:** Transcribe button re-enabled, status shows error in destructive color, messagebox displays error details

### Thread Safety

- Transcription runs in a background thread (not the main tkinter thread)
- UI updates are scheduled via `root.after()` or `root.after_idle()` to safely update widgets from the background thread
- Transcribe button is disabled during processing to prevent concurrent transcriptions
