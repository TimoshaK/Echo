<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User → file dialog | `select_file` / save dialogs return user-chosen filesystem paths |
| Filesystem → application | Read/write of the transcript and subtitle output files |
| Background thread → GUI thread | Engine queues are drained by `poll_progress` / `poll_summary` |
| User → app instance | Event handlers are invoked by tkinter callbacks only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-07 | T (Tampering) | `save_transcription_txt` / `save_transcription_srt` write path | accept | The path comes from `filedialog.asksaveasfilename`, i.e. an explicit user action; only text content is written and `OSError` is surfaced via `messagebox.showerror`. Behaviour unchanged from the baseline. |
| T-06-01 | I (Information Disclosure) | `echo/ui/app.py` imports | mitigate | This module no longer imports `urllib`/`json` at all, so the API key cannot be read or logged here. The `*_color` literals come from `theme.COLORS`, so no credential-bearing config value flows into a widget attribute. Asserted absent in Task 1. |
| T-06-18 | D (DoS) | `poll_progress` / `poll_summary` | mitigate | Both loops drain with `get_nowait()` inside `try/except queue.Empty` and reschedule via `root.after(100, ...)`, so an empty queue cannot busy-spin the GUI thread. The 100 ms cadence is preserved and asserted by the source checks. |
| T-06-19 | T (Tampering) | queue message dispatch | mitigate | Handlers read fixed keys (`type`, `text`, `language`, `segments`, `error`) and only act on the known `type` values; unknown message types are ignored rather than executed. Unchanged from the baseline. |
| T-06-20 | E (Elevation of Privilege) | event handler binding | accept | Handlers are bound by the app to its own methods via tkinter `command=`/`bind`; there is no dynamic dispatch on user-supplied names. |
| T-06-21 | R (Repudiation) | save operations | accept | `messagebox.showinfo` confirms the written path to the user; no audit log is required for a single-user desktop tool. |
</threat_model>
