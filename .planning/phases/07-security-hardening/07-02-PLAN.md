```python
def _restrict_windows_acl(path: Path) -> None:
    """Best-effort owner-only ACL on Windows (SEC-01).

    `os.chmod(0o600)` на Windows не работает: режимные биты не поддерживаются
    (проверено — st_mode остаётся 0o666). Поэтому ACL сужаем через icacls:
    снимаем наследование и выдаём полный доступ только текущему пользователю.

    Любая неудача (нет icacls, не-NTFS, политика) НЕ должна срывать сохранение
    только что введённого ключа — исключения глушим осознанно.
    """
    if os.name != "nt":
        return
    username = os.environ.get("USERNAME") or ""
    icacls = shutil.which("icacls")
    if not icacls or not username:
        return
    try:
        subprocess.run(
            [icacls, str(path), "/inheritance:r", "/grant:r", f"{username}:F"],
            capture_output=True,
            check=False,
            timeout=10,
            creationflags=getattr(subprocess, "CREATE_NO_WINDOW", 0),
        )
    except Exception:
        pass


def _atomic_write_secure(path: Path, text: str, mode: int = CONFIG_FILE_MODE) -> None:
    """Записать файл атомарно и с правами владельца (SEC-01).

    Порядок важен: mkstemp в ТОЙ ЖЕ папке (os.replace атомарен только в пределах
    тома), запись, fsync, chmod, затем os.replace. Пока не выполнен replace,
    целевой файл остаётся прежним; если что-то упало — временный файл удаляется,
    а исходный конфиг не тронут (никаких частично записанных ключей).
    """
    directory = path.parent
    fd, tmp_name = tempfile.mkstemp(dir=directory, prefix=".app_config.", suffix=".tmp")
    tmp_path = Path(tmp_name)
    try:
        with os.fdopen(fd, "w", encoding="utf-8", newline="\n") as handle:
            handle.write(text)
            handle.flush()
            os.fsync(handle.fileno())
        try:
            os.chmod(tmp_path, mode)
        except OSError:
            pass
        os.replace(tmp_path, path)
    except BaseException:
        try:
            if tmp_path.exists():
                tmp_path.unlink()
        except OSError:
            pass
        raise
    _restrict_windows_acl(path)


def save_config(cfg: dict) -> None:
    normalized = json.loads(json.dumps(DEFAULT_CONFIG))
    normalized["llm"].update(cfg.get("llm", {}) or {})
    data = json.dumps(normalized, ensure_ascii=False, indent=2) + "\n"
    _atomic_write_secure(CONFIG_PATH, data)
```

The public signature `save_config(cfg: dict) -> None` is unchanged, and the merge semantics
(`DEFAULT_CONFIG` deep-copied, then `"llm"` updated from `cfg`) are unchanged — only the write
mechanism differs. The trailing `"\n"` in `data` is new and deliberate: it makes the file
POSIX-text-clean and makes the byte-comparison tests deterministic.

class ConfigCorruptError(RuntimeError):
    """app_config.json существует, но прочитать его не удалось (SEC-04).

    Отдельный тип вместо молчаливого отката к DEFAULT_CONFIG: иначе потеря

    """

    def __init__(self, path: Path, detail: str) -> None:

        self.detail = detail
        super().__init__(f"Файл настроек повреждён или недоступен ({path}): {detail}")

```python
def load_config() -> dict:
    """Прочитать конфиг, явно сообщая о повреждении (SEC-04).

    FileNotFoundError -> дефолты: первый запуск это не ошибка.
    Любая другая причина, по которой нельзя получить корректный объект
    (нет доступа, битая кодировка, битый JSON, не тот тип на верхнем уровне
    или в секции "llm"), -> ConfigCorruptError. Молчаливый откат запрещён:
    он скрывает потерю ключа и может отправить запрос на чужой дефолтный URL.
    """
    try:
        raw = CONFIG_PATH.read_text(encoding="utf-8")
    except FileNotFoundError:
        return json.loads(json.dumps(DEFAULT_CONFIG))
    except (OSError, UnicodeDecodeError) as e:
        raise ConfigCorruptError(CONFIG_PATH, f"файл недоступен: {e}") from e

    try:
        cfg = json.loads(raw)
    except ValueError as e:
        raise ConfigCorruptError(CONFIG_PATH, f"некорректный JSON: {e}") from e

    if not isinstance(cfg, dict):
        raise ConfigCorruptError(CONFIG_PATH, "корень файла должен быть объектом JSON")

    llm = cfg.get("llm")
    if llm is not None and not isinstance(llm, dict):
        raise ConfigCorruptError(CONFIG_PATH, "секция 'llm' должна быть объектом JSON")

    # Глубокие копии: DEFAULT_CONFIG не должен оказаться тем же объектом, что и
    # результат, иначе запись через результат мутирует дефолты (было в старом коде).
    merged = json.loads(json.dumps(DEFAULT_CONFIG))
    for key, value in cfg.items():
        if key != "llm":
            merged[key] = value
    merged["llm"] = {**DEFAULT_CONFIG["llm"], **cfg.get("llm", {})}
    return merged
```

`json.JSONDecodeError` is a `ValueError` subclass, so the single `except ValueError` covers it.
`UnicodeDecodeError` is *also* a `ValueError` subclass but it is raised by `read_text`, which sits
in the first `try` — hence it is listed explicitly there.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `app_config.json` ↔ filesystem | The file holds a live plaintext API key; other local users, backup tools and a crash mid-write can all expose or destroy it |
| Config file → application state | The file is user-editable and gitignored; malformed content is a realistic state, not an attack |
| `requirements.txt` → package resolution | An unpinned floor lets an upstream release change the code that runs with the stored key |
| `icacls` subprocess → filesystem ACL | A failed ACL call must never be allowed to abort a save |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-02-01 | I (Information Disclosure) | `app_config.json` permissions | mitigate | Request `0o600` via `os.chmod` on the temp file before the rename (real on POSIX) **plus** a best-effort `icacls /inheritance:r /grant:r "<user>:F"` on Windows, where `chmod` is verifiably a no-op (`st_mode` stays `0o666`). The ACL step is non-fatal by design and asserted never to raise. |
| T-07-02-02 | T (Tampering) / D (DoS) | `save_config` write path | mitigate | Write to a `tempfile.mkstemp` file in the config directory, `flush` + `os.fsync`, then `os.replace`. The destination is only ever swapped by a rename, so no partially written key file can exist; a failure before the rename leaves the previous file byte-identical and deletes the temp file. Locked by two tests that force `os.replace` to fail. |
| T-07-02-03 | R (Repudiation) / I (Information Disclosure) | `load_config` fallback | mitigate | A missing file still yields defaults (first run is not an error), but an unreadable, non-UTF-8, malformed or ill-shaped file raises `ConfigCorruptError` carrying the path and the reason. Silently defaulting previously hid the loss of the API key and could have pointed summarization at a default endpoint without the user's knowledge. |
| T-07-02-04 | T (Tampering) | `requirements.txt` | mitigate | Replace every `>=` floor with an exact `==` pin at the version verified installed in this environment. `numpy` was pinned *down* to `2.4.4` because the old `>=2.5.0` floor was already unmet by the working install. Unpinned ranges let a future malicious or breaking release execute with access to the stored key. |
| T-07-02-05 | I (Information Disclosure) | unused `srt` package | mitigate | Remove `srt>=3.5.3` (verified: no import anywhere in `echo/` or `main.py`) to shrink the supply-chain surface, and remove the two doc claims that it is declared. |
| T-07-02-06 | I (Information Disclosure) | Windows without `icacls`, or a non-NTFS volume | accept | On a system where the ACL step cannot run, the file falls back to the directory's inherited permissions. Residual risk recorded: the data is a personal API key on a single-user desktop, and failing the save would be a worse outcome than an unhardened ACL. The attempt is still made and asserted. |
| T-07-02-07 | D (DoS) | `icacls` subprocess call on every save | mitigate | The call is bounded by `timeout=10`, uses `check=False`, runs with `CREATE_NO_WINDOW` so a GUI process does not flash a console, and swallows every exception. A hostile or hung `icacls` cannot block the UI thread indefinitely. |
| T-07-02-08 | T (Tampering) | `DEFAULT_CONFIG` aliasing | mitigate | Both the load and the save paths build their result from a fresh `json.loads(json.dumps(DEFAULT_CONFIG))` deep copy, and `merged["llm"]` is assembled with a new dict literal, so no caller can mutate the module-level defaults. |
