Update `main.py` to implement the full Phase 1 GUI per UI-SPEC.md:

**Window Setup (already in Task 1, verify):**
- Title: "Whisper Transcriber"
- Size: 500x200, minsize 400x150
- Resizable: True (both)

**Widgets to add:**

1. **Select File button** — `ttk.Button` at grid (0, 0), sticky W, padx=8, pady=8
   - Text: "Выбрать файл" (Russian per UI-SPEC copywriting)
   - Command: calls `select_file` method

2. **File path display** — `ttk.Entry` at grid (0, 1), sticky EW, padx=8, pady=8
   - State: `readonly` when file selected, `normal` when empty
   - Placeholder: "Файл не выбран" (gray text when no file)
   - Width: 40 characters minimum

3. **Status label** — `ttk.Label` at grid (1, 0), sticky W, padx=8, pady=(0, 8)
   - Text: "Нажмите «Выбрать файл», чтобы выбрать аудиофайл для транскрипции"
   - Spans 2 columns (columnspan=2)

4. **Column configuration**: `grid_columnconfigure(1, weight=1)` so entry expands

**Methods:**

`select_file(self)`:
- Call `filedialog.askopenfilename()` with:
  - title="Выберите аудиофайл"
  - filetypes=[("Аудиофайлы", "*.mp3 *.wav *.m4a *.flac *.ogg *.webm"), ("Все файлы", "*.*")]
  - defaultextension=".mp3"
  - initialdir=os.path.expanduser("~")
- If file selected: update entry to show full path, set entry state to readonly, update status to filename
- If cancelled: do nothing (keep current state)

**Error handling:**
- Wrap `askopenfilename` in try/except
- On error: show `messagebox.showerror("Ошибка", "Не удалось открыть файл. Проверьте формат файла и попробуйте снова.")`

**Imports needed:**
- `import os`
- `from tkinter import filedialog, messagebox`
