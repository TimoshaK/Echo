## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User → settings dialog | The API key is typed by the user into a masked entry field |
| Settings dialog → config file | `update_config` persists the key to the gitignored root `app_config.json` |
| App instance → builder functions | Builders mutate the app in place; the parameter is the only coupling |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | I (Information Disclosure) | `echo/ui/settings_dialog.py` key entry | mitigate | The key entry keeps `show="*"`; the module performs no `print`/`logging`, so the value can only reach the config file via `update_config`. Asserted absent in the task's automated check. |
| T-06-14 | T (Tampering) | `echo/ui/build.py` combobox style | accept | `configure_combobox_style` wraps `theme_use("clam")` in `try/except tk.TclError: pass`; a missing theme degrades styling but cannot crash or corrupt state. Preserved verbatim. |
